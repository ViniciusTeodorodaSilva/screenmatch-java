# 🎬 ScreenMatch

Aplicação desenvolvida em **Java** durante meus estudos de desenvolvimento backend, com foco no consumo de uma API externa para busca de informações sobre filmes e séries.

## 🚀 Sobre o projeto

O ScreenMatch permite realizar buscas de filmes e séries através de requisições HTTP a uma API externa.

Durante o desenvolvimento do projeto, pratiquei conceitos importantes do Java e do desenvolvimento backend, como consumo de APIs, manipulação de JSON, orientação a objetos, Collections e tratamento de exceções.

## 🛠️ Tecnologias e conceitos utilizados

- Java
- Programação Orientada a Objetos (POO)
- HttpClient
- Requisições HTTP
- Consumo de API REST
- JSON
- Gson
- Collections
- Records
- Tratamento de exceções
- Git e GitHub

## 📚 Aprendizados

Com este projeto pratiquei:

- Criação e organização de classes em Java
- Encapsulamento e orientação a objetos
- Envio de requisições HTTP
- Consumo de dados de uma API externa
- Conversão de JSON para objetos Java utilizando Gson
- Utilização de Records
- Manipulação de listas e Collections
- Tratamento de exceções
- Versionamento de código com Git e GitHub

## 🔄 Projeto em evolução

Este projeto faz parte da minha jornada de aprendizado em desenvolvimento backend Java e poderá receber melhorias conforme avanço nos estudos.
